# Tabhold

**Рой дронов против волн. Только ты и ИИ.**

Минималистичная 3D RTS на Three.js с продвинутым поиском пути, групповым ИИ и высокой производительностью.  
Без сборщиков и внешних ассетов — работает прямо в браузере.

**Играть:** [tab-hold.vercel.app](https://tab-hold.vercel.app/)

---

## Особенности

- **Flow Fields** — глобальные векторные поля вместо A* на каждого юнита
- **Spatial Hash** — быстрый поиск целей и расталкивание
- **GPU Instancing** — тысячи юнитов при минимальном количестве draw calls
- **Web Worker Pool** — многопоточная симуляция
- **Процедурные карты** — шум Перлина, разные масштабы арены
- **Формации** — шеренга, клин, кольцо
- **Zero-Asset** — вся графика и звук генерируются в рантайме
- Полная поддержка мобильных устройств + PWA
- Русский и английский интерфейс

Просто открой → [tab-hold.vercel.app](https://tab-hold.vercel.app/)
