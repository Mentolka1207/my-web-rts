# 🛰️ Minimal Web RTS: Neo-Drone Swarm & Patrolling AI

Минималистичный трёхмерный прототип стратегии в реальном времени (RTS) на **Three.js** (WebGL), демонстрирующий продвинутые алгоритмы поиска пути, группового поведения и искусственного интеллекта юнитов — с полноценной поддержкой мобильных устройств, режимом survival-волн, 4 тактическими картами, гибкой системой сложности и условиями победы/поражения.

Проект разработан без внешних тяжёлых зависимостей, не требует сборщиков и работает прямо в браузере (включая автономный запуск по протоколу `file:///` без локального веб-сервера).

---

## 🚀 Как запустить

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Mentolka1207/my-web-rts.git
   ```

2. Откройте файл `index.html` в любом современном браузере (десктоп или мобильный) простым двойным кликом либо разверните на статическом хостинге (GitHub Pages).
3. В главном меню выберите карту и сложность, затем нажмите **«▶ Играть»**.

## 🛠️ Технологический стек и архитектура

В проекте реализован ряд фундаментальных систем, использующихся в масштабных коммерческих RTS (таких как Supreme Commander):

### Поиск пути на основе Flow Fields (Поля потоков)

Вместо индивидуального расчёта алгоритма A* для каждого юнита (что привело бы к падению производительности при сотнях объектов), движение реализовано через глобальные векторные поля:

- **Cost Field** (карта стоимостей) — сетка проходимости с препятствиями (1 для свободных клеток, 255 для стен).
- **Integration Field** (карта интеграции) — расчёт расстояний до цели волновым алгоритмом поиска в ширину (BFS на 4-связной сетке с равными весами рёбер на плоском буфере `Int32Array`).
- **Flow Field** (поле направлений) — генерация векторов движения в сторону наименьшего сопротивления по градиенту соседей с LRU-кэшированием до 16 полей и очередью запросов. Юниты просто «плывут» по векторам, огибая любые препятствия.

В игре работают **два независимых поля потоков**: одно ведёт союзные дроны к точке, куда игрок отдал приказ (ПКМ/тап), второе — постоянно нацелено на штаб игрока и ведёт по нему вражеские волны, чтобы приказы игрока и марш противника не конфликтовали.

### Динамические групповые построения (Formations)

- Поддержка трёх типов тактического строя: **Шеренга** (Line, клавиша `Z`), **Клин** (Wedge, клавиша `X`) и **Кольцо** (Circle, клавиша `C`).
  - **Шеренга [Z]**: фронтальное развертывание роя в линию для плотного одновременного огня широким фронтом.
  - **Клин [X]**: стреловидное построение с флагманским острием во главе — эффективно для тарана и рассечения групп противника.
  - **Кольцо [C]**: круговое защитное построение вокруг осадных танков, командира или кристалла ресурсов (радиус кольца динамически масштабируется по числу юнитов отряда).
- Автоматический разворот локальной матрицы смещения строя по вектору движения всей группы.
- Алгоритм плавного слияния векторов: при приближении к цели юниты переключаются со следования общему Flow Field на занятие своих точных персональных позиций в строю.

### Пространственное хеширование (Spatial Grid)

Для стабильных 60 FPS при масштабных баталиях (сотни объектов) реализована система ячеистого пространственного индекса (`js/spatialhash.js`):
- **Zero-allocation структура**: списки ячеек переиспользуются через сброс длины массивов (`.length = 0`), исключая паузы Garbage Collector во время боя.
- **Быстрый поиск целей $O(1)$**: поиск ближайших врагов выполняется строго в радиусе видимости по окрестным ячейкам сетки без полного перебора $O(N \times M)$ всех объектов карты.
- **Оптимизированное расталкивание (Separation)**: коллизии юнитов проверяются внутри ячейки и ровно с 4 соседними ячейками. Каждая пара проверяется ровно один раз, что снижает сложность с $O(N^2)$ до строгого $O(N)$.

### ⚡ Оптимизация рендеринга (GPU Instancing и слияние статики)

При классическом подходе в Three.js 1 500 юнитов, состоящих из составных частей (корпус, крылья, визоры, орудия), создают более **12 000 вызовов отрисовки (Draw Calls)**, перегружая CPU и видеодрайвер.
- **Инстансирование геометрии стен (Static Geometry Instancing)**: все стены карты и их бронированные оголовки объединены в два оптимизированных `THREE.InstancedMesh` (`js/terrain.js`). Это исключило более 200 отдельных мешей и снизило количество вызовов отрисовки стен до **всего 2 Draw Calls**.
- **Слияние статичной геометрии (`mergeBufferGeometries`)**: энерго-рельсы и угловые голографические пилоны периметра (`terrain.js` / `scene.js`), статичные каркасы и ярусы штабов фракций (`models.js`) и парящие кристаллы-спутники ресурсов (`resources.js`) объединены в сплошные составные буферы. Это дополнительно сократило **31 постоянный меш** в сцене до нескольких слитных объектов.
- **Единые композитные геометрии армии**: части дронов объединены в сплошные PBR-геометрии через BufferGeometry Merger (`js/instancing.js`).
- **Снижение Draw Calls с 12 000+ до ~16 для юнитов**: вся армия любого размера отрисовывается всего несколькими вызовами `gl.drawElementsInstanced`.
- **Инстансированные 3D-биллборды полосок HP**: все полоски здоровья и щитов объединены в единый инстансированный меш. Ориентация лицом к камере (Spherical Billboarding) рассчитывается **прямо на GPU в вершинном шейдере**, полностью освобождая процессор от тригонометрии.
- **Инстансированные лучи лазеров и кольца выделения**: единые пакетные вызовы для всех спецэффектов.

### 🧠 Архитектура симуляции и Data-Oriented Design (SoA)

Математическая модель мира отвязана от объектов `THREE.Mesh` сцены (`js/simulation.js`):
- **Плоские типизированные массивы**: позиции (`posX`, `posZ`), скорости (`velX`, `velZ`), здоровье, щиты и состояния хранятся в непрерывных буферах `Float32Array` и `Uint8Array`.
- **Высокопроизводительный цикл в основном потоке**: основной боевой цикл, пространственный хеш, FSM и расталкивание выполняются на фиксированном шаге 30 Гц без выделения динамической памяти (Zero-Allocation), гарантируя стабильный фреймрейт.
- **Прототип Web Worker (`js/sim_worker.js`)**: архитектурный задел для выноса симуляции в фоновый поток через **Transferable Objects** для будущих сетевых режимов.

### ⏱️ Детерминированный фиксированный шаг (Fixed Timestep & Mulberry32 PRNG)

- **Фиксированный квант симуляции**: игровой мир обновляется с детерминированным шагом $\Delta t = 1/30\text{с} \approx 33.33\text{ ms}$, отвязанным от частоты обновления экрана монитора (60/120/144/240 Гц), с защитой от накопления задержек (Spiral of Death Clamping).
- **Mulberry32 PRNG**: генерация случайных событий (разброс блуждания, микро-смещения спавна) переведена на 32-битный сидируемый детерминированный генератор псевдослучайных чисел (`js/prng.js`), гарантируя воспроизводимость реплеев и возможность headless-тестирования.

### Боевая система и ИИ на основе конечного автомата (FSM)

Юниты функционируют на базе расширяемой стейт-машины со следующими состояниями:

- **IDLE** (ожидание) — пассивное сканирование местности на наличие врагов через Spatial Hash.
- **MOVE** (движение) — следование к цели по Flow Field с возможностью отвлечься на угрозу.
- **CHASE** (преследование) — выход из строя и сближение с конкретной целью с огибанием углов стен (алгоритм лучевой проверки видимости Брезенхэма `hasLineOfSight` + поиск вектора обхода `findBypassDirection` в `js/grid.js`).
- **ATTACK** (атака) — остановка на дистанции огня, расчёт кулдауна оружия и стрельба лазерами.

Союзные дроны автоматически считают **вражеский штаб** допустимой целью наравне с обычными дронами — если рядом нет противника ближе, рой сам довершит осаду штаба, стоит только подвести его в радиус обзора.

### Ресурсы, захват точек и производство юнитов

- Ресурс «Энергия» стартует со 100 единиц и растёт пассивно (**+5 в секунду** базово на сложности «Командир», динамически адаптируется выбранной сложностью).
- **Точки сбора ресурсов (Контроль территории)**: на каждой карте расположены 3 кристаллические энергостанции («Альфа», «Центр», «Бета»).
  - Отправка дронов в зону кристалла запускает захват точки (дополнительные юниты ускоряют прогресс).
  - При одновременном нахождении союзников и врагов точка переходит в состояние «Оспаривается» с тревожной пульсацией.
  - Каждая захваченная игроком точка даёт **+3⚡/сек** дополнительного дохода (до +14⚡/сек при контроле всех трёх точек).
  - Точки отображаются ромбами на миникарте (жёлтый — нейтрал, циан — игрок, красный — враг) и имеют 3D-биллборд шкалу прогресса захвата над кристаллом.
- За уничтожение вражеского дрона начисляется **+10 энергии**.
- Панель производства предлагает **три типа дронов**, каждый со своей ролью и ценой; новый юнит появляется у базы игрока через расходящийся кольцевой поиск ближайшей свободной ячейки.

### ⚡ Тактические способности юнитов (Active Abilities)

Каждый класс союзных юнитов оснащён уникальной активной способностью, активируемой через нижнюю тактическую панель (Action Bar) либо быстрыми клавишами:

- **⚡ Форсаж Разведчика (`Q` или `2` / кулдаун 10 сек)**:
  - Мгновенный буст скорости на **+80%** (с 12 до 21.6) на 3 секунды.
  - Сопла двигателей выбрасывают удлинённое пламя и непрерывный неоновый бирюзовый шлейф частиц.
  - Незаменим для молниеносного перехвата нейтральных энергокристаллов, захода врагу во фланг или отступления из засады.
- **⚓ Осадный режим Танка (`R` или `F` или `3` / кулдаун переключения 2.5 сек)**:
  - Танк опускается на грунт и фиксируется якорями (скорость = 0).
  - Дальность атаки возрастает вдвое (с 4.5 до **9.0** клеток).
  - Выстрелы наносят разрушительный **урон по площади (Splash Damage)** в радиусе 2.2 единиц, накрывая плотные скопления штурмовиков противника.
  - Повторное нажатие снимает танк с осады и возвращает мобильность.
- **🛡️ Энергетический щит Дрона (`E` или `1` / кулдаун 12 сек)**:
  - Разворачивает вокруг дрона мерцающий сферический силовой купол на **50 единиц поглощаемого урона** на 6 секунд.
  - Защитный барьер отображается отдельной синей шкалой над полоской HP юнита и поглощает весь входящий лазерный урон до пробития.

### Камера: панорама колёсиком мыши, сенсором и зум

- **Колёсико мыши (MMB Drag)**: зажмите среднюю кнопку мыши (колёсико) и перемещайте курсор — камера с физической точностью 1:1 перемещается над полем боя.
- **Сенсорное перемещение (Touch Sensor)**: на смартфонах и планшетах свайп одним пальцем в режиме «🖐 Карта» плавно передвигает карту. Переключатель `[🖐 Карта / ⬚ Рамка]` в левом нижнем углу позволяет мгновенно выбирать между перемещением карты и выделением отрядов рамкой.
- **Зум**: вращение колёсика мыши либо жест сведения/разведения пальцев (Pinch-to-zoom).
- **Клавиатура**: классическая навигация клавишами W, A, S, D или стрелками.

### Миникарта

- Компактная карта в углу экрана показывает стены, союзников (циан), врагов (красный, с увеличенными метками для Танков и сияющим ореолом для Босса-Левиафана), оба штаба крупными маркерами в цвете фракции, кристаллы сбора ресурсов и рамку текущей области обзора камеры.
- Оффскрин-кэширование статичных препятствий гарантирует нулевую нагрузку на рендер при обновлении миникарты.
- Клик (десктоп) или тап (тач) по миникарте мгновенно переносит камеру в указанную точку.

## 📂 Модульная структура проекта

Кодовая база разделена на независимые специализированные модули в папке `js/` (всего 27 скриптов в проекте):

- **Ядро конфигурации и данных:**
  - `js/config.js` — Глобальные константы, размеры сетки, баланс классов юнитов, scratch-векторы и дебаг-логгер.
  - `js/i18n.js` — Словарь и система мгновенного переключения языков (Русский / English) для всех текстов, способностей и оповещений на лету.
  - `js/storage.js` — **Storage Schema v2**: безопасное сохранение настроек и профиля в `localStorage`, изолированные рекорды по картам и сложностям, валидация типов и автоматическая миграция `v1 → v2`.
  - `js/maps.js` — **MapDef v2**: 4 тактические карты как чистые декларативные данные (Каньон, Арена, Лабиринт, Перекрёсток), валидатор инвариантов `validateMapDef` (BFS-проходимость, чистота баз/кристаллов) и пресеты сложности (Рекрут, Командир, Ветеран).
  - `js/prng.js` — Детерминированный 32-битный генератор псевдослучайных чисел Mulberry32 с поддержкой сидов.
  - `js/audio.js` — Процедурный звуковой движок на Web Audio API: синтез лазеров, щитов, взрывов, способностей, тактических фанфар, космический эмбиент и независимые шины громкости Master/SFX/Music.

- **Сетка, навигация и физика:**
  - `js/grid.js` — Сетка проходимости, конвертация координат (`worldToGrid`, `gridToWorld`), лучевая проверка прямой видимости Брезенхэмом (LOS) и алгоритм обхода углов стен.
  - `js/spatialhash.js` — Пространственная сетка (Spatial Grid) для быстрого $O(1)$ поиска целей и строгого $O(N)$ бесконфликтного расталкивания без аллокаций.

## 🏳️ Игровой цикл: штабы, волны, победа/поражение

### Штабы (HQ)

- На карте стоят два процедурных здания — **штаб игрока** и **штаб противника**, каждый с 500 HP и собственной полоской здоровья.
- Клетки под штабами блокированы для path-finding так же, как обычные стены — юниты и Flow Field физически огибают здания.
- **Уничтожение штаба противника = победа. Потеря своего штаба = поражение.** По завершении партии отображается неоновая карточка **послематчевой статистики** (время матча, число отражённых волн, уничтоженные враги и сбитые боссы, выработанная энергия, произведённые дроны, захваченные точки сбора) и кнопка «▶ Играть снова».

### Волны врагов, составные группы и Босс-Левиафан (Survival Mode)

- Таймер в верхней панели отсчитывает **60 секунд** до следующей волны (за 10 секунд до старта система выдаёт тактическое предупреждение). Интервал волн адаптируется уровнем сложности.
- **Эволюция состава волн:**
  - **Волны 1–2**: базовые Штурмовики (разведка боем).
  - **Волны 3–4**: Штурмовики + быстрые **Разведчики** (молниеносный наскок и обход с флангов).
  - **Волны 5–9**: подключение тяжёлых **Танков** (пробивают строй, поглощают огонь) в связке с Разведчиками и Штурмовиками.
  - **Волна 10 (и каждые 10 волн)**: **Босс «Левиафан»** — гигантский флагманский крейсер с энергетическим щитом и эскортом из Танков и Разведчиков!
- **Механики Босса-Левиафана:**
  - **Силовое поле (Щит 400 ед.):** поглощает любой входящий урон, вспыхивает при попаданиях. Пока щит активен, здоровье босса (600 HP) не уменьшается. При перегрузке щита генерируется энергетический взрыв.
  - **Залповый огонь:** Левиафан сканирует сектор и выпускает веерный лазерный залп по 3 целям одновременно, либо концентрирует тройной залп по одиночной цели.
  - **Награда:** за ликвидацию Левиафана начисляется **+100⚡** энергии.
- **Ответные действия ИИ (Диверсионные группы):**
  - Если игрок захватывает все 3 точки сбора ресурсов («Альфа», «Центр», «Бета»), вражеский штаб немедленно формирует ударную диверсионную группу (2 Разведчика + 1 Танк), нацеленную на ближайший кристалл.
  - Оповещения о диверсиях, приближении босса, захвате/потере точек и нападении на штаб отображаются через неоновый баннер `#tactical-alert`.

## 💥 Эффекты боя и визуализация

- **Высокопроизводительный пул частиц (`js/particles.js`)**: единый меш `THREE.Points` на 512 слотов обслуживает все взрывы и искры за один Draw Call без аллокаций памяти во время боя.
- **Вейпоинт-маркеры приказов**: при клике ПКМ по земле или противнику на поверхности проецируется анимированное расширяющееся кольцо (бирюзовое для перемещения, алое для атаки).
- **Вспышка попадания с бликом оптики**: в точке попадания лазера загорается лучистая вспышка с белым ядром и крестообразным оптическим бликом (Lens Flare Spikes) + искры в палитре фракции.
- **Взрывы**: при гибели юнит рассыпается на огненные кубические обломки с гравитацией, силой импульса и затуханием.
- **Опалённые следы (Кратеры)**: на месте гибели остаётся детализированный след раскалённого металла с тлеющим оранжевым ядром и радиальными трещинами окалины (пул 60 декалей).
- **Неоновый шлейф форсажа**: Разведчик в режиме форсажа оставляет светящийся бирюзовый след перегруженных турбин.

## 🎨 Графика, процедурные PBR-текстуры и 3D-модели

- **Zero Assets & Zero CORS**: все sci-fi текстуры и материалы генерируются динамически через HTML5 Canvas при запуске игры. Проект полностью автономен и открывается двойным кликом по `index.html` без локального веб-сервера.
- **Процедурные карты PBR (Albedo, Bump, Roughness)**:
  - *Поверхность земли*: текстура высокого разрешения (512x512) с титановыми плитами, угловыми монтажными болтами, неоновыми энерго-магистралями и процедурными картами рельефа (`bumpMap`) и шероховатости (`roughnessMap`).
  - *Стены-монолиты*: композитная бронесталь с радиаторными решетками охлаждения, неоновым свечением реактора, предупреждающими шевронами и защитными оголовками.
  - *Периметр арены*: энерго-рельсы по краям карты со светящимися угловыми голографическими пилонами (объединены через `mergeBufferGeometries`).
- **Кинематографичное освещение и постобработка**:
  - `ACESFilmicToneMapping` с экспозицией 1.15 — устраняет выгорание неоновых цветов и обеспечивает сочные контрасты.
  - Мягкие тени `PCFShadowMap` высокого разрешения (2048x2048) со сглаживанием смещения normal bias (Three.js r186). В настройках игры тени можно отключить в один клик для ультра-высокого FPS на слабых устройствах.
  - Контурный свет (`Rim Light`), эффектно подчеркивающий металлические грани и силуэты дронов.
- **Уникальные 3D-модели техники**:
  - **Дрон (Стандартный)**: скоростной квадрокоптер с 4 вращающимися роторами, сдвоенными фронтальными бластерами и сенсорным визором.
  - **Разведчик**: аэродинамический дельта-перехватчик со стреловидными крыльями, килями, панорамным фонарем и сдвоенными соплами.
  - **Танк**: тяжелая осадная платформа с бортовыми бронеэкранами, двуствольным рельсотроном и 4 антигравитационными подушками.
  - **Босс «Левиафан»**: многоуровневый флагманский крейсер с бронекорпусом, реактором и куполом силового поля.
  - **Штабы (HQ)**: командные цитадели с вращающимися радарами, орбитальными голографическими кольцами связи и генераторными пилонами.
  - **Кристаллы ресурсов**: кластер из центрального икосаэдрического кристалла-призмы, 3 парящих кристаллов-спутников и концентрических колец захвата.

## 🔊 Процедурный звук (Web Audio API)

В игре реализован автономный звуковой движок (`js/audio.js`), синтезирующий все аудиоэффекты процедурно в реальном времени с помощью **Web Audio API**:
- **Zero Assets & Zero CORS**: Никаких внешних `.mp3` или `.wav` файлов. Звуки генерируются программно через осцилляторы, частотную модуляцию, белый шум, ADSR-огибающие и Biquad-фильтры. Игра запускается без сбоев из проводника по протоколу `file:///`.
- **Раздельные аудио-шины и регуляторы**: независимое управление громкостью Master, SFX (эффекты) и Music (космический эмбиент) с нормализацией через мастер-компрессор `DynamicsCompressorNode`.
- **Боевые эффекты**:
  - *Лазеры*: лёгкий бирюзовый импульс дронов, агрессивный красный бластер штурмовиков, тяжёлый саб-басовый залп осадных танков и мощный вибрирующий луч Левиафана.
  - *Попадания*: металлический щелчок по броне и резонирующий высокочастотный пинг при поглощении энергощитом.
  - *Взрывы*: белый шум через развёртку низкочастотного фильтра + глубокий спад саб-баса (масштабируется по объёму и длительности для босса и штабов).
- **Способности и тактика**: свист турбины при форсаже Разведчика, гудение энергобарьера Дрона, лязг гидравлики при раскладке Танка.
- **Интерфейс и события**: кибернетические клики выбора, тактические фанфары при захвате/потере точек, гул боевой тревоги перед волной врагов.
- **Космический эмбиент**: непрерывный процедурный sci-fi дрон-эмбиент на расстроенных синусоидальных волнах с переходом тональностей каждые 12 секунд.

## 🧪 Юнит-тесты (Vitest) и CI

Игра по-прежнему запускается двойным кликом по `index.html` — Vitest и тестовый раннер нужны только разработчикам (`devDependencies`).

```bash
npm install
npm test          # однократный запуск всех 128 тестов
npm run test:watch
```

Набор тестов в `tests/` состоит из **7 тестовых файлов и 128 тестов** (100% зелёные):
- `tests/grid.test.js` (20 тестов) — сетка, координаты, препятствия, лучевая видимость (LOS) и обход углов.
- `tests/formations.test.js` (20 тестов) — расчет смещений для Шеренги, Клина и Кольца, масштабирование радиуса.
- `tests/flowfield.test.js` (28 тестов) — BFS-интеграция, генерация векторов, недостижимые клетки, LRU-кэш целей.
- `tests/spatialhash.test.js` (44 теста) — корзины, поиск с приоритетом, расталкивание в режимах spatial и naive.
- `tests/maps.test.js` (6 тестов) — MapDef v2 схемы, валидация 4 карт, проверка периметра, чистоты зон и BFS-достижимости.
- `tests/storage.test.js` (4 теста) — Storage Schema v2, санитизация настроек, валидация профиля, миграция v1 -> v2.
- `tests/geometry.test.js` (6 тестов) — утилита слияния `mergeBufferGeometries`, сохранение атрибутов геометрий.

Автоматизированный CI-пайплайн на **GitHub Actions** (`.github/workflows/test.yml`) запускает тесты на каждый push и pull request в ветку `main`.
