# Tabhold

**Рой дронов против волн. Только ты и ИИ.**

Минималистичная 3D RTS на Three.js с продвинутым поиском пути, групповым ИИ и высокой производительностью.  
Без сборщиков и внешних ассетов — работает прямо в браузере.

**Играть:** [tab-hold.vercel.app](https://tab-hold.vercel.app/)

---

## Особенности

- **Flow Fields** — глобальные векторные поля вместо A* на каждого юнита
- **Spatial Hash** — быстрый поиск целей и расталкивание
- **GPU Instancing** — тысячи юнитов при минимальном количестве draw calls
- **Web Worker Pool** — многопоточная симуляция (при запуске через HTTP)
- **Процедурные карты** — шум Перлина, разные масштабы арены
- **Формации** — шеренга, клин, кольцо
- **Zero-Asset** — вся графика и звук генерируются в рантайме
- Полная поддержка мобильных устройств + PWA
- Русский и английский интерфейс

## Как запустить

### Онлайн
Просто открой → [tab-hold.vercel.app](https://tab-hold.vercel.app/)

### Локально
Нужен [Node.js](https://nodejs.org/) (зависимости ставить не нужно):

```bash
git clone https://github.com/Mentolka1207/my-web-rts.git
cd my-web-rts
node e2e/serve.js
```

Открой <http://127.0.0.1:4173> в браузере.

> Можно открыть `index.html` и двойным кликом, но по `file://` браузер запрещает Web Workers — симуляция пойдёт в одном потоке.

## Управление

### Юниты

| Действие              | Клавиатура / Мышь                    | Мобильные                              |
|-----------------------|--------------------------------------|----------------------------------------|
| Выделение             | ЛКМ / рамка ЛКМ                      | Тап; рамка — в режиме «Рамка»          |
| Все юниты этого типа  | Двойной клик ЛКМ                     | —                                      |
| Вся армия             | `Ctrl+A`                             | —                                      |
| Приказ движения/атаки | ПКМ                                  | Тап по карте при выделенных юнитах     |
| Формации              | `Z` `X` `C`                          | Кнопки                                 |
| Способности           | `Q` `E` `R` (или `1` `2` `3`, `F`)   | Кнопки                                 |

### Камера

| Действие              | Клавиатура / Мышь                    | Мобильные                              |
|-----------------------|--------------------------------------|----------------------------------------|
| Движение              | `W` `A` `S` `D` (+`Shift` — быстрее) | Свайп в режиме «Карта»                 |
| Зум                   | Колёсико мыши                        | Щипок                                  |
| Панорама              | Зажатое колёсико (MMB)               | Свайп в режиме «Карта»                 |
| К армии / к базе      | `Space` / `H`                        | —                                      |

### Прочее

| Действие              | Клавиатура / Мышь                    | Мобильные                              |
|-----------------------|--------------------------------------|----------------------------------------|
| Пауза                 | `P` / `Esc`                          | Кнопка                                 |
| Профайлер             | `F3`                                 | Кнопка «Дебаг»                         |

## Технологии

- Vanilla JavaScript + Three.js
- Data-Oriented Design (SoA)
- Fixed Timestep + детерминированный PRNG
- Vitest + Playwright
- Дизайн-система на токенах (WCAG AA)
