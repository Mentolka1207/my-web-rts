# Плейтест волн на больших картах (`T-09`)

Цель — проверить пункт DoD `T-09` «на 1024 волны доходят до штаба игрока, давление ощущается» не только
headless-моделью (`tests/gameplay.test.js`), а в настоящей игре. Сырые данные — [`playtest-T09.json`](playtest-T09.json).

## Как снято

- **Скрипт:** [`scripts/playtest_waves.js`](../scripts/playtest_waves.js) (`npm run playtest`). Игра целиком в Chromium:
  `index.html`, `js/fsm.js`, flow field, спавн волн из `js/ai.js`, экономика. Реальный цикл заморожен
  (`isGamePaused = true`), симуляция шагается вручную по 1/30 с, как `fastForward` в `e2e/fixtures.js`, поэтому прогон
  детерминирован по сиду.
- **Игрок — скрипт «оборона у штаба»:** раз в 3 с игрового времени строит юниты по кругу
  дрон → дрон → разведчик → танк, пока хватает энергии и армия меньше 40; приказов не даёт, точки не захватывает
  (доход только пассивный), юниты сами вступают в бой у базы.
- **Параметры:** сложность «Офицер» (`normal`), сид `11`, 4 биома × 256 / 512 / 1024, до 12 волн или до поражения.
- **«Дошёл до базы»:** враг волны оказался ближе 8 клеток (`8 * CELL_SIZE` = 32) к центру штаба игрока.
- **Стенд:** Chrome for Testing `158.0.8127.36` (headless shell, программный WebGL SwiftShader), Linux, 2 ядра;
  коммит `3f0451e`, дата `2026-11-27`. Скорость железа на результат не влияет: шаг симуляции фиксированный.

## Выводы

- **Волны на 1024 доходят до штаба.** До радиуса 8 клеток добираются 75 % врагов (на 256 — 89 %); на трёх картах
  из четырёх штаб падает — так же часто, как на 256.
- **Давление сопоставимо с 256, а местами выше.** Медиана выдержанных волн — 11 против 12; «Перекрёсток» на 1024
  проигрывается на 8-й волне против 10-й на 256. Пик врагов одновременно на 1024 выше (30–34 против 18–24): волна
  ещё в пути, когда выходит следующая.
- **Где 1024 мягче.** Первый враг волны приходит через ~64 с (интервал волн «Офицера» — 60 с), то есть с отставанием
  примерно на одну волну, а волна растягивается по скоростям сильнее (87 с против 65): разведчики приходят раньше,
  танки — позже, и оборона бьёт их по частям. На «Каньоне» 1024 штаб не получил урона за 12 волн.

**Итог для DoD `T-09`:** по этому прокси давление на 1024 есть и по исходу матча не слабее, чем на 256.
Ощущение живого игрока скрипт не заменяет: человек захватывает точки (больше дохода) и маневрирует, поэтому
пункт про субъективное ощущение остаётся за ручной партией.

## Ограничения

- Один сид (`11`) и один стиль игры; разброс между картами большой (на 256 — от поражения на 10-й волне до
  выживания без урона), выводы по одной карте ненадёжны.
- Штабы на всех картах стоят в одних позициях (`build-log.md`, «Известные исключения»), поэтому расстояние
  штаб–штаб одинаково для всех биомов одного размера: 334 / 696 / 1420.
- «Потери союзников за волну» в json считаются по номеру текущей волны, а не по тому, кто убил.

## Повторить

```bash
npx playwright install chromium
npm run playtest -- --sizes 256,512,1024 --maps canyon,arena,maze,crossroads --out docs/playtest-T09.json
```

Прогон 12 карт занял ~12 мин на 2 ядрах (1024 — 92–145 с на карту).
