# design/ — дизайн-система Tabhold

Снята с кода коммита `36e225f` (`style.css`, inline-стили `index.html` и `js/ui.js`) и со скриншотов Playwright
(1280×800 и 390×844). С 2026-10-31 игра подключает `tokens.css` первым в `index.html`, а `style.css` написан только на
токенах — см. `build-log.md` в корне.

| файл | что это |
|---|---|
| `build_tokens.py` | единственный источник значений. Пишет три файла ниже и проверяет контраст. Python 3, только стандартная библиотека |
| `tokens.json` | токены как данные; `color.surface-*` = итоговый цвет стекла поверх худшего фона сцены |
| `tokens.css` | CSS custom properties + базовые правила (`font: inherit`, `:focus-visible`, `prefers-reduced-motion`) |
| `tokens.effective.js` | итоговые цвета стекла для стенда (`file://` не даёт читать JSON через fetch) |
| `components.css` | эталонные примитивы только на `var(--…)`: 0 hex, 0 rgba-литералов |
| `components.md` | спецификация каждого компонента: варианты, размеры, состояния, токены, a11y, что сейчас не так |
| `index.html` | стенд примитивов; открывается двойным кликом |
| `contrast-report.txt` | вывод `build_tokens.py --check` |

```bash
python3 design/build_tokens.py           # пересобрать токены + проверить контраст (exit 1 при провале AA)
python3 design/build_tokens.py --check   # только проверка
```

## Контраст: было → стало

Порог AA: 4.5:1 для обычного текста, 3:1 для крупного (от 24px, или от 18.66px bold) и для рамок/фокуса
(WCAG 2.x SC 1.4.3 и 1.4.11). Фон под полупрозрачными панелями считается по худшему замеру сцены: верх стены
`#00a180`, 90-й перцентиль пикселей сцены на скриншоте HUD.

| пара | было | стало |
|---|---|---|
| белый текст на кнопках HUD и меню | `#0077ff`: **4.13:1** (провал) | `action #006be6`: 4.95:1 |
| белый текст на «Играть» / `.primary-btn` (18px bold < 18.66px) | `#00a2ff`: **2.76:1** (провал) | текст `#04101f` на `#00a2ff`: 6.93:1 |
| заголовки секций профайлера F3 | `#64748b`: **3.86:1** (провал) | `text-muted #94a3b8`: 7.16:1 |
| остальные 30 пар | проходили | без изменений, все ≥ AA |

Итог: **33 пары, 0 провалов AA**. Проверено двумя независимыми реализациями: `build_tokens.py --check` и
`contrast.py` из пакета replica. Совпадение до сотых.

Не покрыто проверкой: редкие яркие блики. Самый светлый пиксель в области сцены на том же скриншоте — `#fef8cf`.
Если такой блик или взрыв окажется прямо под панелью, текст HUD может на мгновение потерять контраст. Стекло с альфой
0.9 это смягчает, но отдельно я это не измерял.

## Что ещё нашлось при съёмке (подробно в `components.md`)

- Кнопки и селекты рисуются **Arial**, остальной текст `sans-serif`: кнопки не наследуют шрифт.
- 16 разных размеров шрифта (9–42px) → 8 ступеней; минимум 11px.
- Стиля `:focus` у кнопок нет; `aria-*` и `role` в `index.html`: 0; `prefers-reduced-motion` не учитывается.
- На 390×844 кнопки «Скрыть / Звук / Пауза» 24px высотой: ровно минимум AA по WCAG 2.2 SC 2.5.8, ниже 44px (AAA, SC 2.5.5).
- Панели HUD перекрываются на телефоне; FPS-панель на десктопе ложится на кнопку «Карта».
- В профайлере F3 устаревшие цифры («~235 KB», «~648 KB», «~16 calls») и подпись «Web Worker», хотя симуляция в главном потоке.
