# Паритет: Minimal Web RTS

Сравнение исходной версии `a1919fb` (2026-10-28, на ней делали recon) со сборкой `35dabce` (2026-11-02).
Оценка функций: `parity.py` из replica-diff по `features.csv`. Снимки и проверки поведения: Chromium (Playwright), программный WebGL.

## Итог

**Вердикт: к продаже пока не готово.** В матрице 38 обязательных функций (must), готовы 36. Две частично: решение по лицензии своего кода и карты. Открытых багов S1/S2 нет (`bugs.md`: BUG-001..004 исправлены).

| Показатель | Значение |
|---|---|
| Функции исходной версии | **99.1%** (106 из 107 весовых баллов, 39 строк) |
| Обязательные функции исходной версии | 30 из 30 |
| Обязательные функции всего (включая новые) | 36 из 38, 2 частично |
| Открытые баги S1/S2 | 0 |

Как считается: вес must 3, should 2, could 1; `yes` = 1, `partial` = 0.5. Строки `skip` и функции, которых не было в исходной версии, в процент не входят. Поэтому две частичные обязательные функции на 99.1% не влияют, но на вердикт влияют.

## Чего не хватает

Из функций исходной версии:
- [should] **Headless-баланс на реальном коде**, частично. `scripts/headless_wave_test.js` берёт типы юнитов из `config.js`, но состав волн у него своя копия (строка 23).

Из новых обязательных функций:
- [must] **Решение по лицензии своего кода перед продажей**, частично. Репозиторий под MIT, и форк может продать кто угодно. Решать тебе, лучше вместе с юристом.
- [must] **Несколько карт**, частично. У 4 пресетов штабы и точка спавна стоят в одних и тех же клетках (`maps.js:66-68, 106-108, 146-148, 186-188`). У генератора на шуме Перлина штабы тоже всегда в углах (`maps.js:532-534`).

## Исправлено в матрице

- **«Симуляция в Web Worker»**: было `stub/stub`, стало `no/yes`. Значение `stub` `parity.py` не понимает. В `a1919fb` воркер не вызывался. С `b94bfa4` главный цикл отдаёт шаг в `SimulationWorkerPool` (`main.js:97-116`). Проверено на `35dabce`: пул включён, в Chromium по HTTP работают 2 воркера. При открытии через `file://` симуляция остаётся в главном потоке.
- **«Несколько карт»**: в примечание добавлен генератор на шуме Перлина. Статус не изменился.
